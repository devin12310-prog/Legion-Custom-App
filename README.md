# Legion Custom  v1.2.0

Legion Space-style quick menu + game launcher for the **first-gen Legion Go (Z1 Extreme)**.

## Install (one time)

1. Install **Python 3.10+** (Microsoft Store is fine)
2. Download ZIP from GitHub → extract
3. Double-click **`install.bat`**
   - Installs packages
   - Adds **Legion Custom** to Start Menu
   - Adds shortcut to Desktop
   - Launches the app automatically

## Features

- Quick Menu layout inspired by official Legion Space
- Performance modes + live CPU / RAM stats
- TDP control + fan mode (Smart / Full Speed) with curve visual
- Resolution pills (1280x800 / 1600x1000 / 1920x1200) + 60/144 Hz
- Big red **Force Close Legion Space**
- Built-in OptiScaler downloader + Lossless Scaling detection
- Official AMD 25.30.44 driver button
- One-click **Update from GitHub** (no more re-downloading ZIPs)

## Update later

Open Quick Menu → **APP UPDATES** → **Check & Update from GitHub**

## Right Legion Button

Map it with PowerToys or AutoHotkey to run:

```
path\to\run.bat --menu
```

That opens the app with the Quick Menu already visible.
